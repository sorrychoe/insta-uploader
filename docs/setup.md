# 설정 및 사용 가이드

처음 한 번만 설정하면 이후에는 사진과 제품 정보만 입력해 게시할 수 있습니다.

## 1. 준비물

| 항목 | 용도 | 비용 |
|---|---|---|
| 인스타그램 비즈니스/크리에이터 계정 | 게시 대상 | 무료 |
| Meta 개발자 앱 + 장기 액세스 토큰 | 프로그램이 인스타에 게시할 권한 | 무료 |
| OpenAI API 키 | 소개글·해시태그 생성 | 사용량만큼 과금 (건당 수 원 수준) |
| Cloudinary 계정 | 게시 중 사진을 잠시 올려 두는 곳 | 무료 플랜으로 충분 |

## 2. 계정 준비

### 2-1. 인스타그램 계정 전환
인스타 앱 → **설정** → **계정 유형 및 도구** → **프로페셔널 계정으로 전환**에서 비즈니스 또는 크리에이터를 선택합니다.

### 2-2. Meta 개발자 앱과 토큰
1. [Meta 개발자 콘솔](https://developers.facebook.com/)에서 앱을 만들고 **Instagram** 제품을 추가합니다.
2. 연결 방식은 **Instagram API with Instagram Login**을 사용합니다. Facebook Login 토큰은 사용할 수 없습니다.
3. 본인 인스타 계정을 연결하고 `instagram_business_basic`, `instagram_business_content_publish` 권한으로 **장기 액세스 토큰**을 발급합니다.
4. 다음 세 가지를 메모해 둡니다.
   - 인스타 계정 ID
   - 장기 액세스 토큰
   - 토큰 만료일

> 본인 계정에만 쓸 때는 앱을 개발 모드로 두어도 됩니다. 다른 사람의 계정에서 쓰려면 Meta 앱 검토를 받아야 합니다.

### 2-3. OpenAI API 키
[OpenAI API 키 페이지](https://platform.openai.com/api-keys)에서 키를 만들고 **Billing**에서 결제 수단을 등록합니다. 결제를 등록하지 않으면 글 생성이 실패합니다.

### 2-4. Cloudinary
[Cloudinary 콘솔](https://console.cloudinary.com/)에 가입한 뒤 대시보드에서 **Cloud name**, **API Key**, **API Secret**을 확인합니다.

## 3. 프로그램 설정

1. [Releases](../../../releases)에서 `InstaUploader.exe`를 내려받아 실행합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 코드 서명이 없어 나타나는 경고입니다.
2. **설정** 탭에서 아래 항목을 입력합니다.

| 항목 | 입력 값 |
|---|---|
| OpenAI API 키 | 2-3에서 만든 키 |
| OpenAI 모델 | 기본값 `gpt-4.1-mini` 그대로 사용 |
| 인스타 계정 ID / 장기 액세스 토큰 | 2-2에서 메모한 값 |
| 인스타 API 버전 | 기본값 그대로 사용 |
| Cloudinary 클라우드 이름 / API 키 / API 비밀키 | 2-4에서 확인한 값 |
| 고정 해시태그 | 매번 붙일 브랜드 태그 (선택) |
| 토큰 실제 만료일 | **발급 화면에 나온 실제 날짜** |
| 기본 말투 | 자주 쓰는 말투 |

3. **OpenAI 저장 및 연결 테스트**, **인스타 저장 및 연결 테스트**, **Cloudinary 저장 및 연결 테스트**로 각 서비스를 따로 확인합니다. 누른 서비스의 설정만 저장하고 검사하므로 다른 서비스는 미설정 상태여도 됩니다. **설정 저장**은 고정 해시태그·기본 말투를 포함한 전체 설정을 저장합니다.

알아 두면 좋은 점:
- 토큰 만료일 칸에는 기본으로 오늘부터 60일 뒤 날짜가 들어가 있습니다. 예전에 발급한 토큰을 쓴다면 반드시 실제 만료일로 고쳐 주세요.
- API 키·토큰 칸은 가려져 표시됩니다. 빈칸으로 저장하면 기존 값이 그대로 유지됩니다.

## 4. 게시하기

1. **새 게시물** 탭에서 JPG/PNG 사진 1~10장을 선택하거나 끌어다 놓습니다. 끌어서 또는 위로/아래로 버튼으로 순서를 바꿀 수 있습니다.
2. 제품명과 핵심 특징을 입력합니다. 가격, 타깃 고객, 스토어 링크, 추가 요청은 선택 항목입니다.
3. **생성**을 누릅니다. 결과가 마음에 들지 않으면 **다시 생성**을 누르거나 직접 고칩니다.
   - **사진 참고**에 체크하면 첫 번째 사진을 AI에 함께 보내 사진에 맞는 글을 씁니다. 비용이 조금 늘어납니다.
4. 글은 2,200자, 해시태그는 30개 이하여야 합니다. 본문에 넣은 해시태그도 개수에 포함됩니다.
5. **업로드** → 최종 확인 창에서 **게시하기**를 누릅니다. 게시가 끝나면 게시물 링크를 열어 볼 수 있습니다.

원본 사진 파일은 수정되지 않습니다. 업로드용 사진은 인스타 규격에 맞게 자동 변환되며, 비율이 맞지 않는 사진은 잘라내지 않고 흰 여백을 붙입니다.

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| 인스타 테스트에서 Meta 오류가 표시됨 | 오류의 HTTP 상태와 Meta 코드로 원인을 확인합니다. 권한 오류는 앱에 `instagram_business_basic`, `instagram_business_content_publish`가 설정되어 있는지 확인하고, 계정 오류는 Instagram Login용 계정 ID인지 확인합니다. |
| "인스타 연결이 만료되었거나 해제되었습니다" | Meta 개발자 콘솔에서 장기 토큰을 새로 발급해 설정에 입력하고, 만료일도 고칩니다. |
| "토큰 자동 갱신에 실패했습니다" | 위와 같습니다. 프로그램을 오래 켜지 않아 토큰이 만료되면 자동 갱신이 되지 않습니다. |
| "게시 한도에 도달했습니다" | 잠시 후 **인스타 저장 및 연결 테스트**로 남은 한도를 확인합니다. |
| 글 생성 실패 | OpenAI 결제 등록과 잔액을 확인합니다. |
| 기록에 **결과 확인 필요** 상태가 남음 | 게시 도중 통신이 끊긴 경우입니다. 중복 게시를 막기 위해 자동으로 다시 시도하지 않으므로, 인스타 앱에서 실제로 올라갔는지 먼저 확인한 뒤 필요할 때만 다시 올립니다. |
| 기록에 삭제할 public ID가 표시됨 | Cloudinary에서 임시 사진을 지우지 못한 경우입니다. Cloudinary 콘솔의 **Media Library** → `insta-uploader` 폴더에서 해당 사진을 삭제합니다. |
| 이전 기록을 불러왔는데 사진이 없음 | 기록에는 사진 경로만 저장됩니다. 원본 파일을 옮기거나 지웠다면 사진을 다시 선택합니다. |

## 6. 데이터 저장 위치

| 내용 | 위치 |
|---|---|
| 일반 설정 | `%APPDATA%\InstaUploader\config.json` |
| 작성 중인 글 (자동 저장, 재실행 시 복원) | `%APPDATA%\InstaUploader\draft.json` |
| 게시 기록 | `%APPDATA%\InstaUploader\history.sqlite3` |
| API 키·토큰 | Windows **자격 증명 관리자** → Windows 자격 증명 → `InstaUploader` |

PC를 바꿀 때는 `%APPDATA%\InstaUploader` 폴더를 복사하고, API 키·토큰은 새 PC의 설정 탭에서 다시 입력합니다.
